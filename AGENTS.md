# Book Authoring Agent

This repository contains a technical computer science book written in LaTeX.

## Authoritative instructions

Before writing book content, read:

1. `WRITER_INSTRUCTIONS.md` (style rules shared by every book)
2. `BOOK_INSTRUCTIONS.md` (mission, reader, and architecture of this book)
3. `main.tex` and `preamble.tex`

For each unit, also read its specification under `chapters-instructions/`.

Do not read all chapter instruction files unless the task explicitly
requires a whole-book analysis.

## Repository

The existing LaTeX structure is authoritative.

Preserve:
- document class and geometry (`main.tex`);
- macros and environments (`preamble.tex`);
- bibliography configuration (BibTeX + natbib, `references.bib`);
- code-listing mechanism (`pythoncode`, `\py{}`);
- chapter organization (`chapters/contents.tex`, generated by
  `scripts/plan.sh init`);
- cross-reference conventions (label prefixes listed in `preamble.tex`).

Do not create an alternative LaTeX architecture.

## Writing workflow

When writing a unit:

1. Read the corresponding unit specification.
2. Inspect preceding units through `book-plan/summaries/` and
   `book-plan/ledger.md` (grep chapters only for specific details).
3. Write the unit directly in LaTeX in its target file.
4. Compile the complete book with `scripts/build.sh`.
5. Fix compilation errors and references.
6. Run `scripts/lint-unit.sh <unit-id>`.
7. Verify compliance with the unit specification.

## Quality

The manuscript must be technically rigorous and computationally
motivated.

Do not leave TODO, FIXME, TBD, placeholder text, missing proofs,
or citation placeholders.

Follow all style rules in `WRITER_INSTRUCTIONS.md`.

## Completion

A unit is complete only when:
- its specification has been satisfied;
- required exercises are present;
- notation is consistent;
- references work;
- the complete book compiles.

## Multi-agent loop

The book is written one unit per agent session, coordinated by the
`book-master` agent (`.opencode/agents/`) or by
`scripts/run-book-loop.sh`. Unit order and status live in
`book-plan/plan.tsv`. See `README.md` and `book-plan/README.md`.
